# World Map Tooltip Scale

Ein kleines Addon für **World of Warcraft: Wrath of the Lich King 3.3.5a**.

**Vorübergehende Lösung für die fehlerhafte Tooltip-Skalierung bei Verwendung von Leatrix Maps.**

Bei der Nutzung von Leatrix Maps kann es vorkommen, dass der Mouseover-Tooltip auf der Weltkarte nicht korrekt skaliert wird und unabhängig von den eingestellten UI-Skalierungswerten in Standardgröße erscheint.

Dieses Addon ermöglicht es, die Größe des Weltkarten-Tooltips unabhängig anzupassen.

## Installation

1. Die Datei `WorldMapTooltipScale.zip` entpacken.
2. Den Ordner `WorldMapTooltipScale` nach `World of Warcraft\Interface\AddOns\` kopieren.
3. Das Spiel starten und das Addon in der Addon-Liste aktivieren.

## Funktionen

- **Standardwert:** 60 %
- Ein Minimap-Button öffnet per Linksklick ein kleines Einstellfenster.
- Über einen Regler lässt sich die Tooltip-Skalierung individuell anpassen.
- Der gewählte Wert wird dauerhaft pro WoW-Account gespeichert.
- Der Minimap-Button wird von gängigen Sammeladdons wie **MBB (MinimapButtonButton)** erkannt.

## Hinweis

Dieses Addon dient als vorübergehender Workaround für die fehlerhafte Skalierung des Weltkarten-Tooltips bei Verwendung von Leatrix Maps unter WoW 3.3.5a.

Es verändert ausschließlich die Skalierung des Tooltips und behebt nicht die eigentliche Ursache des Problems in Leatrix Maps.
