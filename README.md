# World Map Tooltip Scale

A small addon for **World of Warcraft: Wrath of the Lich King 3.3.5a**.

**Temporary workaround for incorrect tooltip scaling when using Leatrix Maps.**

When using Leatrix Maps, the mouseover tooltip on the world map may not scale correctly and can appear at its default size regardless of the configured UI scaling settings.

This addon allows you to adjust the world map tooltip scale independently.

## Installation

1. Extract `WorldMapTooltipScale.zip`.
2. Copy the `WorldMapTooltipScale` folder into `World of Warcraft\Interface\AddOns\`.
3. Launch the game and enable the addon in the addon list.

## Features

- **Default scale:** 60%
- Left-click the minimap button to open a small settings window.
- Adjust the tooltip scale using a slider.
- The selected scale is permanently saved per WoW account.
- The minimap button is compatible with common button collection addons such as **MBB (MinimapButtonButton)**.

## Note

This addon provides a temporary workaround for incorrect world map tooltip scaling when using Leatrix Maps on WoW 3.3.5a.

It only adjusts the tooltip scale and does not fix the underlying issue in Leatrix Maps itself.
